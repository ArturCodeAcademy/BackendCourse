# Lecture 01 Code Basics

Project: `Lecture01.CodeBasics`

This project is a separate runnable code walkthrough for Lecture 01. It is not the main live demo application. Its purpose is to show basic C# code elements explicitly and slowly enough for a 90-minute beginner lesson.

## Covered Concepts

- Variables and naming.
- Constants.
- Basic types: `string`, `decimal`, `int`, `long`, `byte`, `float`, `double`, `bool`, `char`.
- Arithmetic operators and operator precedence.
- Integer division vs decimal division.
- Console input and output.
- Converting text to numbers with `Parse`.
- Safer conversion with `TryParse`.
- Basic formatting with `ToString` and invariant culture.
- Simple `if`, `else if`, and `else` conditions.
- Boolean values and logical operators.
- String concatenation and string interpolation.
- `var` as simple type inference.
- One-dimensional arrays.
- Array indexing and `Length`.
- Array initializer syntax.
- Basic `for` and `foreach` over arrays.
- Two-dimensional rectangular arrays.
- Jagged arrays.

## Run

```bash
dotnet run --project Code/Lecture01_Introduction_to_CSharp_and_DotNET/Lecture01.CodeBasics/Lecture01.CodeBasics.csproj
```
