# Lecture 01 Demo

Project: `Lecture01.Demo`

This is the first live coding demo for the course. It intentionally stays simple and uses a single `Program.cs` file.

## Concepts Demonstrated

- Console input and output.
- String variables.
- Decimal parsing.
- String interpolation.
- The basic program flow: input -> processing -> output.

## Run

```bash
dotnet run --project Code/Lecture01_Introduction_to_CSharp_and_DotNET/Lecture01.Demo/Lecture01.Demo.csproj
```

Example input:

```text
Expense name: Coffee
Amount: 4.50
Currency: EUR
```

Example output:

```text
You spent 4.50 EUR on Coffee.
```
