# Lecture 02 - Conditions, Loops and Methods

Lecture 02 turns the first linear console program into a small interactive application.

## Projects

- `Lecture02.Demo` - live demo with a menu: add expense, show current expense, exit.
- `Lecture02.CodeBasics` - runnable walkthrough for boolean logic, comparisons, conditions, loops, methods, validation, and scope.

## Main Idea

```text
while application is running
    show menu
    read command
    execute operation
```

## Run

```bash
dotnet run --project Code/Lecture02_Conditions_Loops_and_Methods/Lecture02.Demo/Lecture02.Demo.csproj

dotnet run --project Code/Lecture02_Conditions_Loops_and_Methods/Lecture02.CodeBasics/Lecture02.CodeBasics.csproj
```
