# Lecture 03 - Collections and Data Structures

Lecture 03 solves the next problem: the application can work with one item, but real applications need many items.

## Projects

- `Lecture03.Demo` - menu application that can add, list, find, delete, and summarize multiple expenses.
- `Lecture03.CodeBasics` - runnable walkthrough for arrays, `List<T>`, `Dictionary<TKey,TValue>`, `HashSet<T>`, `enum`, and generics.

## Main Ideas

- Arrays have fixed size.
- `List<T>` is the main collection for this lecture.
- Dictionaries are useful for lookup by key.
- Hash sets keep unique values.
- Enums give names to fixed choices.
- Generics let one collection idea work with different types.
