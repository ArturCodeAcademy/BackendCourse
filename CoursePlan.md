# Course Plan

Course: Basics of Internet Technologies 2: Back-end Programming and Database Management

The course introduces new technologies only after students have met the problem that the technology solves.

## Pedagogical Sequence

```text
Basic C#
    -> Console Application
    -> Collections and JSON
    -> OOP
    -> Interfaces and Strategy
    -> Layers
    -> Services and Repositories
    -> Users and ownership in Console
    -> Dapper
    -> Entity Framework Core
    -> HTTP
    -> Simple isolated Web API
    -> DTOs and API design
    -> API + Layers + EF Core + Dependency Injection
    -> Configuration and error handling
    -> Blazor client
    -> ASP.NET Core Identity
    -> Authorization
    -> Final Backend Project
```

## Lecture List

1. Introduction to C# and .NET
2. Conditions, Loops and Methods
3. Collections and Data Structures
4. Files, JSON, Exceptions and LINQ
5. Classes and Objects
6. Interfaces, Abstraction, Composition and Polymorphism
7. Strategy Pattern and Dependency Thinking
8. From Spaghetti Code to Layers
9. Services, Repositories, Validation and Multiple Users
10. ADO.NET and Dapper
11. Entity Framework Core Fundamentals
12. EF Core Relationships and Migrations
13. How HTTP and the Web Work
14. First ASP.NET Core API: API Layer Only
15. DTOs, Validation and Better API Design
16. Real Backend: API + Layers + EF Core + Dependency Injection
17. Practical Backend Architecture, Configuration and Errors
18. Blazor as a Simple API Client
19. ASP.NET Core Identity and Real Authentication
20. Authorization, Ownership, Security and Final Project

## Milestone Checkpoints

- Milestone 01 - Basic Console Application, after Lectures 3-4.
- Milestone 02 - OOP + Persistence, after Lecture 7.
- Milestone 03 - Layered Multi-user Console Application, after Lecture 9.
- Milestone 04 - Database Application, after Lecture 12.
- Milestone 05 - Basic Web API, after Lecture 15.
- Final Project - Full backend application, after Lecture 20.
