# Course Plan

Course: Basics of Internet Technologies 2: Back-end Programming and Database Management

The course introduces a tool only after students have met the problem it solves. Each meeting contains a 3-hour backend session and a connected 1.5-hour database session.

## Pedagogical Sequence

```text
Basic C#
    -> Console application
    -> Collections and JSON persistence
    -> Classes and objects
    -> Interfaces and abstraction
    -> Layered application
    -> Services, validation, users and ownership
    -> SQL access with Dapper
    -> Entity Framework Core
    -> HTTP and Web API
    -> DTOs and API design
    -> Real backend architecture
    -> Configuration, authentication and final defence
```

## Lecture List

1. Introduction to C# and .NET
2. Conditions, Loops and Methods
3. Collections and Data Structures
4. Files, JSON, Exceptions and LINQ
5. Classes and Objects
6. Interfaces and Abstraction
7. From Spaghetti Code to Layers
8. Services, Repositories, Validation and Multiple Users
9. SQL Access with Dapper
10. Entity Framework Core Fundamentals
11. EF Core Relationships and Migrations
12. HTTP and the First ASP.NET Core Web API
13. DTOs, Validation and API Design
14. Real Backend: API, Layers, EF Core and Dependency Injection
15. Configuration, Error Handling, Identity, Authentication and Final Defense

## Connected Database-Course Work

Students keep one domain idea across both subjects. Database work designs and queries the same entities that the backend application models and later persists.

- Early meetings: tables, keys, basic queries, filters, grouping, and joins for the chosen domain.
- Middle meetings: constraints, relationships, normalization, SQL data changes, and performance basics.
- Later meetings: the backend application connects to the same schema through Dapper and EF Core.

## Milestone Checkpoints

- Milestone 01 - Basic Console Application, after Lecture 04.
- Milestone 02 - OOP + Persistence, after Lecture 06.
- Milestone 03 - Layered Multi-user Console Application, after Lecture 08.
- Milestone 04 - Database Application, after Lecture 11.
- Milestone 05 - Basic Web API, after Lecture 13.
- Final Project - Full backend application, after Lecture 15.
